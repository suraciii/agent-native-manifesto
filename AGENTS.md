# Agent instructions

This repository defines an independent Agent Native application manifesto and a working-draft specification.

- Use simple English in English documents and concise, natural Chinese in Simplified Chinese documents. Use short sentences and consistent domain terms.
- English is the content baseline. Keep corresponding translations aligned in the same change, including scope, requirement levels, examples, and evidence limits.
- Write Agent Native without a hyphen in project prose. Preserve URLs and the original names of cited works.
- Keep the manifesto in `README.md`, reasoning in `docs/`, requirements in `spec/`, and illustrations in `examples/`. Mirror reader documents under `zh-CN/` for Simplified Chinese; share repository instructions, scripts, and licenses.
- State requirement scope and separate normative obligations from examples and external standards.
- Keep the model independent of a vendor, protocol, runtime, and application architecture.
- Reuse existing interface standards. Add concepts only for a demonstrated use case.
- Keep requirement references and evaluation coverage consistent when editing the specification.
- Do not claim implementation, protocol support, certification, or evaluation results without evidence.
- Keep private information and transient work records out of published content.
- Do not push to `main` directly; open a pull request for every change.
