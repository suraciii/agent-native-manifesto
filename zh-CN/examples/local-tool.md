# 本地工具示例

[English](../../examples/local-tool.md) | 简体中文

本设计将[应用模型](../docs/application-model.md)和[核心规范](../spec/core.md)应用于本地图像工具。它**尚未实现或评估**。

## 用户任务与环境

用户向编程 Agent 提出请求：

> 生成长边不超过 1600 像素的副本。保留原图，先给我看三个样本，再处理其余图片。

宿主提供 shell 执行能力和经过授权的文件系统访问。Agent 理解任务；已安装的工具检查和缩放图像。工具没有模型运行时、服务器、账户数据库或持久任务系统。

本例从已知且已安装的工具出发，不展示如何从需要发现产品；AN-01 仍需单独评估。

## 能力与上下文

| 能力 | 输入 | 结果与效果 |
| --- | --- | --- |
| 检查图像 | 输入路径 | 尺寸、格式及其他已说明的元数据；不改变内容 |
| 缩放图像 | 输入路径、尺寸上限、输出路径 | 按已说明的宽高比策略生成新图像 |
| 验证输出 | 输出路径与预期约束 | 文件能否解码，以及所检查的约束是否成立 |

帮助文档覆盖用途、版本、格式、操作契约和失败情况。一份简短的“检查—缩放—验证”指南即可，无需单独的 Skill。检查提供输入的当前事实。

机器模式输出一条格式有明确定义的结果记录。进度与诊断使用独立通道。错误标明失败的输入或条件，并使用文档规定的错误通道及非零退出状态。图像字节写入输出文件，不放入状态 JSON。

## 完整路径

1. Agent 阅读帮助，在宿主权限内检查格式与输出策略。
2. 它检查输入、选择三个样本，并选择能保留原图的输出路径。
3. 工具生成三个副本，返回路径与元数据。验证检查解码和尺寸；Agent 在可用查看器中展示实际样本。
4. 用户要求长边不超过 1200 像素。Agent 在不同路径生成新样本，保持此前副本不变。
5. 查看后，Agent 将约定设置应用于剩余输入。逐文件结果标明已完成的输出与失败。
6. Agent 返回选定的副本，供用户文档使用，并与此前样本区分。工具退出后，文件仍由用户掌控。

样本查看属于 Agent 的任务约定；工具不会在缩放前强制验证用户本人的决定。调用之间暂停无需任务队列。外部编辑会在后续检查中可见。普通查看器即可支持参与，无需工具自建界面。

## 失败与纠正路径

**目标已存在。** 操作拒绝覆盖已有输出，并在修改它之前失败。

**写入中断。** 拟议实现先写临时文件，再在文档明确支持的文件系统上，通过原子且不覆盖的操作发布文件。发布前，最终输出不存在；发布后，即使进程在报告成功之前停止，输出也可能已存在。

调用方在重试前检查并验证目标。检查未必能证明是哪个调用方创建了文件，这一不确定性应保持明确。仅有原子发布不能保证崩溃后的持久性。

**批次部分完成。** 逐文件结果区分已完成输出、失败和剩余输入。批次不是全有或全无的事务。

**偏好改变。** 新尺寸影响后续输出，不改变已有样本。尺寸检查成功不能决定用户是否喜欢图像。
