# 报告服务示例

[English](../../examples/reporting-service.md) | 简体中文

本设计将[应用模型](../docs/application-model.md)和[核心规范](../spec/core.md)应用于持续工作。它**尚未实现或评估**。能力名称不规定命令或端点。

## 用户任务与环境

用户向 Agent 提出请求：

> 整理本周的客户问题报告。发布前先给我一份草稿复核。

远程服务读取获准访问的记录、维护草稿，并发布已批准的修订版本。它可以采用确定性构建程序，也可以使用内部研究 Agent。

发布需要指定复核者本人的决定。复核者可以是请求者，也可以是另一位获准用户。准备或发布权限不能提供这一决定。

## 产品发现

本例中，宿主能够搜索获准访问的公司应用目录。Agent 从用户的报告需要出发搜索；请求没有提供产品名称或服务地址。服务条目说明它能从客户记录生成可编辑草稿、提供供核查的来源引用，并列明支持的来源、访问条件和发布前所需的复核。条目链接到产品入口。

Agent 可以在使用前判断服务是否符合请求。来源不兼容或访问条件不满足，都可能成为选择其他产品的理由。目录只是发现路径的示例，不是必需架构。

## 能力与上下文

入口说明范围、提供方、访问路径、要求和费用。经过授权的读取提供来源记录、工作状态、草稿和决定。指引链接到操作契约，提供贯通来源选择、起草、复核和发布的推荐路径，并说明条件和结果检查方式。

| 能力 | 调用方提供什么 | 服务负责什么 |
| --- | --- | --- |
| 搜索客户记录 | 时间范围、账户范围、相关筛选条件 | 授权、搜索限制、带日期的记录与引用 |
| 创建报告工作 | 目标、范围、来源选择、适用限制 | 已接受的方向、工作标识与修订版本、执行状态 |
| 读取工作 | 工作标识 | 已接受的方向与修订版本、执行事实、待作出的决定、可用产出物 |
| 调整报告方向 | 工作标识、预期工作修订版本、修订后的目标或来源范围 | 经过验证的方向与修订版本；明确说明对剩余工作和草稿的影响 |
| 读取或修改草稿 | 草稿标识；写入时提供预期修订版本 | 内容、修订版本、来源、冲突检查 |
| 记录复核决定 | 决定对象的修订版本，以及来自声明的复核路径的证据 | 经过验证的复核者、决定、对象和范围 |
| 发布修订版本 | 确切修订版本、所需权限、受支持时使用的重复操作标识 | 验证、外部可见性、发布记录 |
| 获取或导出报告 | 报告标识、修订版本、请求的呈现形式 | 获准访问的内容或产出物引用、来源修订版本、发布状态、明确说明的导出转换 |
| 请求取消 | 工作标识 | 工作能否停止，以及哪些效果保留 |

复核路径通过 Agent 无法凭委托权限代为完成的确认，验证复核者的身份、角色和决定。账户访问能力和调用方提供的执行者字段不是证据。如果来源和范围可以验证，可信宿主可以传递决定证据，也可以经由 Agent 转交。

方向变更应报告其对剩余工作与草稿的影响。它本身不会重写内容；重写需要经过修订版本检查的更新。

## 完整路径

1. 找到服务后，Agent 阅读能力契约，取得读取记录和准备草稿的访问权限。准备权限不意味着发布权限。
2. 它读取范围明确、带日期的记录。明确的截断提示引导它缩小查询或获取更多细节。
3. 服务接受工作，返回标识与状态路径，而不是声称已完成。
4. 请求者获得带来源引用和覆盖限制的草稿，可通过视图或文档查看。
5. 请求者说“重点关注付费客户”，并保存了对一个段落的编辑。Agent 使用已观察的工作修订版本更新已接受的方向，然后读取当前草稿，再准备更新。基于旧草稿修订版本的写入返回冲突。Agent 协调新范围与请求者已保存的编辑，再提交修改后的内容。
6. 指定复核者检查修订版本、覆盖范围、受众和不确定性，然后通过复核路径批准或拒绝。对象或条件变化后，需要重新评估。经过验证的决定在其范围内仍可复用；一般委托不能替代从未发生的复核。
7. 通过批准与权限检查后，Agent 请求发布。服务返回持久引用，说明发布了什么、发布到哪里。
8. 更换宿主或会话后，获准的 Agent 可以获取工作标识、方向、决定和结果，无需依赖模型的私有推理。
9. 请求者导出报告，然后通过访问管理交接撤销委托访问，并验证其状态。策略说明保留规则和进行中工作的处理方式。断连、撤销权限和撤回报告仍是不同操作。

## 失败与纠正路径

**缺少本人的决定。** 即使拥有发布权限且草稿已就绪，Agent 也不能在缺少必要决定时发布。服务指出待完成的交接。已通过身份验证但不具备复核者角色的用户不能批准；批准缺失、被拒绝或无法验证时，阻止发布。

**Agent 声称已获批准。** 服务不接受 Agent 的声明作为决定证据。只有能够验证来源、对象和条件时，才接受转交的证据。

**发布后响应丢失。** 检查发布记录，或在已说明的去重范围和保留期内安全重复。保证过期后，不要假定重复仍然安全。

**来源消失。** 标明覆盖缺口。只有依法保留且仍可访问时，才能引用留存快照；仅有来源链接不能保证证据长期可用。

**外部交付部分完成。** 记录每个目标的已知结果。一个目标失败不会抹去另一个目标的成功；撤回是具有独立限制的另一项操作。

**用户在工作中取消。** 先记录请求，再记录是否生效。根据已说明的策略保留草稿；取消不会撤销发布。

**访问权限被撤销。** 后续操作执行修改后的授权。策略说明进行中的工作是停止、暂停，还是完成已经提交的效果。

## 面向人的视图与继续使用

视图在 Agent 使用的同一修订版本上呈现来源覆盖、草稿差异与决定。未保存的编辑与已提交的修改保持区别。

Agent 可以请求精简的状态记录或差异，而不必接收呈现载荷。导出内容标明其来源修订版本，以及对下一个应用有实质影响的信息损失。
