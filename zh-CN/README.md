# Agent Native 宣言

[English](../README.md) | 简体中文

**优先为代表用户行动的 Agent 设计应用。**

**Agent Native 应用**为代表用户行动的 Agent 提供能力、清晰的指引和当前事实。用户仍能检查结果、直接参与并调整工作。

## 宣言

### 应用首先为用户的 Agent 而设计

让 Agent 能从用户需要出发发现产品，清楚了解其帮助、条件和限制。提供贯通操作、结果和异常处理的完整路径。可委托的工作不应依赖模拟人的界面导航；必要的人类决定和访问步骤应有明确交接。应用执行其负责的规则与权限约束。

### 上下文与能力一同交付

提供清晰的指引和当前事实，供宿主或 Agent 纳入模型输入。为常见任务提供可直接采用的路径，说明条件、重要选择和结果检查方式。已知的用法不应依赖反复猜测和失败来发现。

指引支持 Agent 按用户目的组织和调整工作，不能替用户确定目的或授予权限。

### 让工作跨越应用边界

用户的工作可以延续到产品之外。提供能用于后续活动的能力和结果，并明确含义、来源和获准的访问方式。小型操作与完整工作流，都可以参与更大的任务。

### 委托行动，保留人的主导

用户可以检查和编辑结果、调整方向、改变授权或接管工作。让已提交的修改可供 Agent 的后续操作获取。区分对未来工作的调整与已经产生的效果。

对于必须由人作出的决定，应要求负责的用户本人作出。委托权限不能代替这一决定。

用户在自身权限和责任范围内选择委托的程度。直接参与本身也可以有价值。

## 状态与范围

这是一份独立的**工作草案**，不是获得背书的标准。示例是设计，并非经过评估的实现；本项目不认证应用。

语言理解可以由用户的 Agent 或宿主承担。应用可以提供自己的界面和 Agent，同时支持外部 Agent。本项目不要求特定协议、服务器或 SDK 包。应根据所评估的工作和访问路径确定要求的适用范围。
