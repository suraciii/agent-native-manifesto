# Agent Native 宣言

[English](../README.md) | 简体中文

**优先为代表用户行动的 Agent 设计应用。**

**Agent Native 应用**为代表用户行动的 Agent 提供所需的能力、知识和当前上下文。用户仍能检查结果、直接参与并调整工作。

## 宣言

### 展示产品如何提供帮助，吸引用户的 Agent

在目标 Agent 为用户寻找帮助的渠道中呈现产品。从用户的工作出发，说明产品能提供什么帮助，而不只是罗列功能或协议。明确使用条件和限制，让产品的主张对应到实际提供帮助的能力。

### 设计 Agent 完成工作所需的完整路径

围绕受支持的结果，设计所需的操作、上下文、结果和异常路径。为人的决定和访问步骤提供明确的交接。应用执行其负责的规则和权限约束。

任务可以跨越多个应用。每个应用提供的能力与结果，都应能用于后续活动。

### 提供能力，也提供使用能力所需的知识

说明每项操作做什么、何时适用、会改变什么，以及如何检查结果。提供当前事实与反馈，包括部分结果和不确定性。

推荐的方法应说明其假设。指导可以帮助 Agent 选择手段，却不能替代用户的目的或授予权限。

### 让人的修改在后续工作中生效

用户可以检查和编辑结果、调整方向、改变授权或接管工作。让已提交的修改可供 Agent 的后续操作获取。区分对未来工作的调整与已经产生的效果。

对于必须由人作出的决定，应要求负责的用户本人作出。委托权限不能代替这一决定。

用户在自身权限和责任范围内选择委托的程度。直接参与本身也可以有价值。

## 状态与范围

这是一份独立的**工作草案**，不是获得背书的标准。示例是设计，并非经过评估的实现；本项目不认证应用。

语言理解可以由用户的 Agent 或宿主承担。应用可以提供自己的界面和 Agent，同时支持外部 Agent。本项目不要求特定协议、服务器或 SDK 包。应根据所评估的工作和访问路径确定要求的适用范围。
